Perturb the inputs

Each slider shifts that channel across the whole 72-hour history by a constant amount, then re-runs the model. Zero returns the published forecast exactly.

What this is. A sensitivity probe, not a physical counterfactual. Shifting Bz by a few nT asks “what would this model output if its input had read differently”, which is not the same as asking what the magnetosphere would have done. The model has no physics in it; it has correlations from 2012–2015.

Why some hours are missing. The scrubber only visits the 8,262 hours of 2017 that passed the causal completeness rules in docs/PROTOCOL_AMENDMENTS.md. Hours with missing inputs, including parts of the September storm, were never scored and are not invented here.
